================================================================================
                        HOW IT WORKS
================================================================================

1. LOAD DASHBOARD
   - fetchAdminDashboard() gets all data
   - Includes: totalUsers, activeUsers, expiredUsers,
              todayRegistrations, upcomingRenewals, etc.
   - Data stored in dashboard state

2. DISPLAY COUNTS
   - Expired badge shows: panel.expiredUsers
   - Registration badge shows: panel.todayRegistrations
   - Notification bell shows: unreadNotifications count

3. REFRESH ACTION
   - Click refresh button
   - Calls loadDashboard()
   - Re-fetches all data
   - Updates all counts
   - Notification panel refreshes

4. NOTIFICATION DROPDOWN
   - Click bell icon to open
   - Shows all notifications
   - Mark as read/unread
   - Delete individual notifications
   - Refresh notifications list
