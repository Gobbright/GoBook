================================================================================
                         DATA FLOW
================================================================================

USER EXPIRY COUNTDOWN:
1. System checks subscriptionEndDate field
2. Calculates days remaining
3. Shows badge on expiry page
4. Color changes based on urgency

REMINDER PROCESS:
1. Admin clicks "Send Reminder"
2. Frontend sends to /admin/send-reminder/{userId}
3. Backend creates AdminRecord entry
4. Admin notification appears in dashboard
5. System triggers user notification
6. User receives email/push notification
7. Record saved for audit trail

NOTIFICATIONS RECEIVED:
Admin Dashboard:
- "Renewal Reminder for [UserName]" appears
- Shows in Admin Records section
- Tracks all reminders sent

User:
- Receives email notification
- Contains renewal deadline
- Call-to-action to renew
- Push notification (if enabled)
