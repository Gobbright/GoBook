🚀 HOW TO USE:
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. START THE APPLICATION
   ├─ Backend:  npm start (in backend/)
   └─ Frontend: npm run dev (in frontend/)

2. OPEN BROWSER
   └─ http://localhost:5174/#/admin-login

3. LOGIN TO ADMIN PANEL
   Admin ID:  admin
   Password:  admin@123
   Or click: Quick Login button

4. VIEW DASHBOARD
   ✓ See 4 stat cards (Businesses, Users, Invoices, Products)
   ✓ See all 30+ collections in data tables
   ✓ Search to filter collections
   ✓ Click Refresh to reload data

5. NAVIGATE (Desktop)
   ✓ Use sidebar menu on the left
   ✓ Sections: Overview, Management, Finance, Operations

6. NAVIGATE (Mobile)
   ✓ Click hamburger menu icon
   ✓ Browse available sections
   ✓ Menu closes on selection

7. LOGOUT
   ✓ Click Logout button in sidebar
   ✓ Returns to login page
