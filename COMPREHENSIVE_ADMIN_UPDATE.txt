================================================================================
                         HOW IT WORKS
================================================================================

MAIN CONTENT LAYOUT:
1. Top Section (Blue Highlighted)
   - Active Users (Main View)
   - All active subscribed users displayed
   - Full details visible

2. Below Main
   - Trial Users section
   - Expired Users section
   - Blocked Users section
   - Each with all user details

EXPIRY COUNTDOWN:
1. System checks subscription end date
2. Calculates days remaining
3. Shows color-coded badge:
   - 3 days left: Amber/Orange
   - 2 days left: Orange
   - 1 day left: Red
   - Expired: Dark Red

REMINDER PROCESS:
1. Admin clicks "Send Reminder" button
2. System sends to backend: /admin/send-reminder/{userId}
3. Backend creates AdminRecord with reminder details
4. Admin receives notification in dashboard
5. User receives email/push notification
6. Records are logged in system for audit trail
