================================================================================
                      DATABASE SCHEMA (Backend)
================================================================================

Notification Model:
{
  id: ObjectId,
  type: String, // "new_user", "expiry_1day", "expiry_2day", "expiry_3day", "payment", "reminder"
  title: String, // "New User Registration", "Subscription Expiring in 1 Day", etc
  message: String, // Detailed message
  adminId: ObjectId, // For admin notifications
  userId: ObjectId, // For user notifications
  relatedUserId: ObjectId, // The user this notification is about
  relatedId: ObjectId, // Link to user/payment/etc
  read: Boolean, // Default: false
  deleted: Boolean, // Default: false (soft delete)
  createdAt: Date,
  updatedAt: Date,
  readAt: Date // When marked as read
}

Indexes:
- { adminId: 1, read: 1 }
- { createdAt: -1 }
- { type: 1 }

================================================================================
                       NOTIFICATION WORKFLOW
================================================================================

1. NEW USER REGISTRATION
   When: AppUser created
   Action: Create "new_user" notification
   Admin sees: "New User: [Name] registered"
   Badge: "Today Registrations" increments

2. SUBSCRIPTION EXPIRING
   When: 3 days before expiry
   Action: Create "expiry_3day" notification
   Badge: "Expiring in 3 days" count increments

   When: 2 days before expiry
   Action: Create "expiry_2day" notification
   Badge: "Expiring in 2 days" count increments

   When: 1 day before expiry
   Action: Create "expiry_1day" notification
   Badge: "Expiring in 1 day" count increments
   Admin can send reminder from here

3. REMINDER SENT
   When: Admin clicks "Send Reminder"
   Action: Create "reminder_sent" notification
   Admin sees: "Reminder sent to [User]"
   User sees: Renewal reminder in their notification

4. PAYMENT RECEIVED
   When: Payment processed
   Action: Create "payment_received" notification
   Admin sees: "Payment received from [User]: Rs. [Amount]"
